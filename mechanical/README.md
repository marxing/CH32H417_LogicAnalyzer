# 机械外壳

本目录包含 CH32H417 逻辑分析仪的 STEP 外壳模型：

```text
CH32H417_LogicAnalyzer_Enclosure.step
```

源文件来自项目工作区的 `外壳-CH32H417逻辑分析仪PCB模型.STEP`，为便于 GitHub、CAD 软件和跨平台工具使用，发布副本采用 ASCII 文件名。

## 使用注意

- 模型应与嘉立创开源硬件平台上的最新 PCB 版本配套核对；
- 打印或加工前检查 USB-C、探针端子、TFT、按键、螺柱和 PCB 边缘间隙；
- 不同打印工艺需要自行加入装配公差和材料收缩补偿；
- 当前模型作为工程参考提供，未声明防水、跌落、绝缘或量产模具验证。
